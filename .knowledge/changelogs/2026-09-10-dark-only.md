# Drop the light theme

**Date:** 2026-09-10

## What changed

- One palette, the neogames.online one. The eduardotres light set, the
  `prefers-color-scheme` block and the `[data-theme]` scopes are gone.
- Deleted `src/components/ThemeToggle.tsx`, `src/lib/theme.ts`, the toggle in the
  header and the anti-flash script in `index.html`.
- **Renamed the tokens.** They were eduardotres names pointing at neogames values,
  which only held together while both palettes shared them: `cream` → `night`,
  `card` → `panel`, `mist` → `raise`, `stone` → `mute`, `navy`/`azure` → `gold`,
  `sky` → `blue`, `haze`/`frost` → `glow`/`glow-strong`.

## Why

Asked for.

## Notes

The rename was the point of doing this properly, not an extra. With the light theme
gone, `bg-cream` meant near-black and `bg-navy` meant gold — names that would send
the next change in exactly the wrong direction.

Verified with the OS set to **light**: the page still renders on `#090c11` and no
`data-theme` attribute is set. There is no light path left to fall into.
